| D-M8-1 library | discord.js 14.27.0 vs @discord-interactions (HTTP-only) vs raw @discordjs/rest | discord.js ^14.27.0 | Gateway + REST + builders + interaction handling in one maintained package; v14 line actively maintained (RESEARCH row 2); live smoke test under Bun passes (row 12) | 1 | High (swap lib behind thin adapter) | none |

| D-M8-6 expiry reminders recipient | DM the linked user vs post to a configured channel vs both | Post to configured admin channel (LP_BOT_REMINDER_CHANNEL_ID); never DM | Developer Policy forbids unsolicited contact; DMs "not directly related to maintaining functionality" are named (RESEARCH row 10). | D-M8-7 admin gating | Discord permission only vs api-role only vs both | Both: `default_member_permissions: ManageGuild` on admin commands (RESEARCH row 6) AND all privileged actions go through the admin API with an admin/owner-role token (api enforces role server-side, doc §15) | doc §15 "Admin permission checks happen server-side via the admin API"; the Discord-side bit is UX, the api-side bit is the real gate | 1 | High | none |

| D-M8-10 scheduler | in-process interval loop vs external cron | In-process hourly loop, virtual-clock injectable for tests | doc §15 "Scheduled job for expiry reminders and role cleanup"; single-process deployment (D-M8-2 options #2); role sync is sequential REST (rate budget, RESEARCH row 7) | 1 | High | none |
