# DECISIONS-M7 — session 2 addendum (Lua §11 checks module)

Module M7 session 2, decided 2026-10-10 (PM) after RESEARCH-M7-S2. Continues
the session-1 table (D-M7-1..10). Tier numbering follows doc.md "Decision
authority".

| # | Decision | Evidence | Tier |
|---|---|---|---|
| D-M7-11 | **Env digest does NOT feed session/payload key derivation (honest scope pin).** §11's "integrity checksums feed key derivation" (§10.2 item 9) is implemented at the CONTAINER level by M6 (build-hash-selected constKey chain, decoy on mismatch — RUNTIME-M6 §4). A client environment digest cannot be a derivation input: the server cannot recompute it, and a transmitted digest is forgeable (doc §3 client-never-trusted). The module instead exposes `digest()` (SHA-256 over the baseline identity snapshot) for the init's decoy-path variation and tamper detail. | S2-1 | 1 |
| D-M7-12 | **Checks module = `loader/checks/env_checks.lua`, factory-chunk style, Lua 5.1-syntax.** `return function(Crypto, Env)` mirroring M3's modules (S2); pcall-guarded everywhere; degrades to "no checks" (never blocks load on a check that cannot run — a check that cannot run is not a signal). Zero globals, zero prints, zero notifications (§11 silent failure). | S2, S2-S3 | 1 |
| D-M7-13 | **Check set (all pinned from D-M7-5):** (a) `identity` — tostring identity-over-time over the pinned critical-function set {loadstring, getfenv, getgenv, setfenv, rawget, rawequal, debug.sethook (when present), hookfunction/getconnections/newcclosure (UNC, when present)} + the resolved request fn; captured twice at t0 (active-swap catch) + re-captured at run; (b) `headers` — SDK-set table snapshot before the call, diff after: unknown additions (first successful call teaches the executor's normal injection set) and removed/changed SDK-set entries; keys case-folded; (c) `timing` — median of 5 sha256(fixed 64B buffer) samples ≥ 20× the baseline median (9 samples captured at init); (d) `env` — baseline-vs-run self comparison: global types, executor identity string, version string. Failure names: `identity.changed`, `headers.injected`, `headers.modified`, `timing.inflated`, `env.changed`. | S2-2, S2-3, S2-4, S2-5; D-M7-5 | 1 |
| D-M7-14 | **Header teaching = first successful request only, additive set.** The taught set is the union of post-call additions observed on the FIRST successful call; later additions outside the set (and outside what the SDK itself set for that call) are `headers.injected`. Teaching is per-instance (per session run), not persisted — executor updates that change the injection set at most cost one false signal on the first call after update, never a silent miss. | S2-3; doc §1.2.9 | 1 |
| D-M7-15 | **Tamper reporting = the module owns a minimal heartbeat client.** `report(session_token, failure)` POSTs `{v:1, session_token, tamper:{check, detail}}` to `/auth/<script_id>/heartbeat` with the same proof-header formula as M3's sdk (S2), pcall-guarded; the response is read ONLY for transport success (delivered true/false) and NEVER acted on (§11: no signal that the report was acted on). One failure per heartbeat (D-M7-6 wire); the caller reports the first failure in pinned order. No retry loop — a lost report costs one signal, a retry loop costs detectable traffic patterns. | S5; D-M7-6 | 1 |
| D-M7-16 | **Silent no-load contract lives with the caller (init), module enforces its own silence.** `run()` returns the failures array (empty = clean); it NEVER prints, raises, or notifies. The integration contract (documented in `loader/checks/README-M7-CHECKS.md`, msg'd to glm1 + the M13 owner): capture at init start → run before payload fetch → on any failure: report(session_token, failures[1]) then return generic failure (no explanatory message), per doc §11. | S2, S4; doc §11 | 1 |
| D-M7-17 | **`digest()` = SHA-256 hex over the sorted baseline identity lines.** Deterministic for the same environment; consumed by the init for decoy-path variation (e.g. choosing among equivalent load strategies) and included in tamper detail when non-empty. NOT a key-derivation input (D-M7-11). | S2-1, D-M7-11 | 1 |
